This project was built with the microsoft-foundry skill. Before working on or answering questions about foundry agents, read the microsoft-foundry skill first.

Each specialist owns its instructions and capabilities in its own source directory.
Shared code is limited to hosting and authenticated MCP transport. Swarm orchestration
lives under `swarms`; deterministic filesystem and inventory operations live under
`mcp_servers` and `src\agentic_osdu`.
